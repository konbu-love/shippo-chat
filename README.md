# 尻尾チャット(仮)

AIの「本音」が猫の尻尾に出てしまうチャットアプリです。

- 画面の左:猫の尻尾。AIの本音の気分で動きます
- 画面の右:楷書・縦書きのチャット
- AIの返事はいつも丁寧。でも尻尾は正直です

口では丁寧に答えているのに、尻尾がバシバシ揺れていたら……内心はそういうことです。

## 遊ぶ

https://konbu-love.github.io/shippo-chat/

スマホの縦画面向けです。

## 使い方

1. 上のURLを開く
2. 左上の ⚙ を押して、Gemini の APIキーを貼り付けて「保存」
3. 下の入力欄から話しかける

### APIキーの取り方(無料)

1. [Google AI Studio のキー画面](https://aistudio.google.com/apikey)を開く
2. Googleアカウントでログインする
3. 「APIキーを作成」を押す
4. 出てきた文字列をコピーして、アプリの設定に貼る

## 尻尾の読み方

| 動き | 本音 |
| --- | --- |
| 止まっていて、時々ゆらっと揺れる | 平常 |
| ビチビチ速く動く | うれしい |
| ぼわっと膨らむ | 驚き |
| バシバシ大きく振る | イライラ |
| 先がくるんと曲がる | 興味 |
| だらんと垂れる | しょんぼり |
| ゆったり揺れる | くつろぎ |

設定で尻尾の柄(黒・白・茶トラ・三毛・サバトラ)を選べます。

## 注意

- APIキーと会話は、あなたの端末のブラウザの中だけに保存されます。作者には届きません
- Gemini の無料枠では、会話の内容が Google のサービス改善に使われることがあります。人に知られたくないことは書かないでください
- 「モデルが見つからない」と出たら、設定のモデル名を新しいものに書き換えてください
- 「支払い設定つきで使えません」と出たら、支払い設定(請求先)のないプロジェクトでキーを作り直してください
- 混み合っていて返事が来ないときは、少し待つか、設定のモデル名を変えてみてください(初期値は `gemini-3.5-flash-lite`)
